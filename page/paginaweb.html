Cómo empezar en HTML

HTML (HyperText Markup Language) es el lenguaje que usamos para crear la estructura de una página web. Con él podemos definir títulos, párrafos, imágenes, enlaces ¡y mucho más!

1. Lo que necesitas

  • Un editor de texto: VS Code, Sublime Text, Atom o incluso el bloc de notas.
  • Un navegador web: Chrome, Firefox, Edge o el que prefieras.

2. Crear tu primer archivo

  1. Abre tu editor de texto.
  2. Crea un archivo nuevo y guárdalo como index.html.

3. Estructura básica de HTML

Copia este código en tu archivo:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>¡Hola, mundo!</h1>
  <p>Esta es mi primera página en HTML.</p>
</body>
</html>

4. Ver tu página

Guarda el archivo, haz doble clic sobre index.html y se abrirá en tu navegador. ¡Ya creaste tu primera página web!

5. Próximos pasos

  • Añadir imágenes con <img>.
  • Crear enlaces con <a>.
  • Hacer listas con <ul> y <ol>.
  • Dar estilos básicos con CSS.

¿Qué es <!DOCTYPE html>?

<!DOCTYPE html>

Indica al navegador que el documento está escrito en HTML5. Debe ir siempre al inicio de tu archivo.

Visualización: No se muestra en la página, pero permite que el navegador interprete correctamente el HTML5.
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<title>Mi primera página</title>
</head>
<body>
<h1>¡Hola, mundo!</h1>
<p>Esta es mi primera página en HTML.</p>
</body>
</html>

La etiqueta <html>

<html lang="es"> ... </html>

Define el inicio y el final de tu documento HTML. El atributo lang indica el idioma principal.

Visualización: No se muestra directamente, pero todo el contenido de la web está dentro de esta etiqueta.

La cabecera <head>

<head> <meta charset="UTF-8"> <title>Título</title> </head>

Contiene metadatos, el título y enlaces a hojas de estilo o scripts. No se muestra en la página.

Visualización: El título aparece en la pestaña del navegador, los metadatos no se ven pero afectan el funcionamiento.

El cuerpo <body>

<body> ...contenido visible... </body>

Todo lo que está dentro de <body> se muestra en la página web.

Visualización: Todo el contenido que ves en la web está dentro de <body>.
